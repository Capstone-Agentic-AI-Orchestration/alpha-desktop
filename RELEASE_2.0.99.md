# Alpha Desktop 2.0.99 — Local AI usage and providers

- Manage local provider runtimes and sign-in from Settings → Providers.
- Open the sidebar usage panel for supported provider-reported account limits.
- Review Alpha-launched token usage and separately labeled reported and estimated costs in Analytics → AI Usage.
- Restore the approved staging database baseline while retaining the later chat-skills migration.

Usage and provider sessions are local to the desktop. Cost estimates are API-equivalent values, not provider invoices. Claude subscription limits may be unavailable through its supported CLI interface.
