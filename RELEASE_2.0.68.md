# Alpha Desktop 2.0.68

This release brings the workspace MCP catalog into the Developer workflow.

- Admins can add the Playwright MCP server with one click from MCP Servers.
- MCP server definitions are shared by the active workspace and can be granted per persona.
- Persona runs receive only the workspace servers granted to that persona; browser settings show server metadata without credential values.
- Cloud-hosted admin catalog access now works alongside desktop execution.
